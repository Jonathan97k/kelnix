# Kelnix Portfolio & Solutions

Professional portfolio and technology showcase website for **Kelnix**, featuring advanced software architecture, intelligent automation, and flagship platforms.

## 🚀 Features
- **Modern Responsive Design:** Crafted with high-performance Vanilla CSS and a sleek dark-tech aesthetic.
- **Core Capabilities:** Showcases software architecture, intelligent automation, and enterprise security auditing.
- **Flagship Solutions:** Highlights production-ready platforms such as *Kelnix Lead Finder* and *Kelnix Automated Core*.
- **Interactive Elements:** Smooth scrolling, responsive mobile menu, and interactive contact messaging.

## 🛠️ Project Structure
```text
kelnix-website/
├── index.html       # Main landing page
├── styles.css       # Custom high-performance styling
├── script.js        # Interactive UI logic
├── vercel.json      # Vercel deployment configuration
└── README.md        # Documentation
```

## 📦 Deployment on Vercel
1. Import this repository into [Vercel](https://vercel.com).
2. Leave build settings as default (static site).
3. Click **Deploy**.
