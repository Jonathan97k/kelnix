# Kelnix website

A responsive static portfolio website for Kelnix, a digital solutions business based in Malawi.

## Run locally

Python 3 is sufficient for a local preview:

```bash
python3 -m http.server 8000
```

Open http://localhost:8000.

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — accessible mobile navigation and footer year
- `vercel.json` — Vercel static-site routing

## Before public launch

- Add a verified Kelnix business email address and/or WhatsApp number.
- Connect a real contact workflow before advertising an enquiry form.
- Replace concept projects with genuine work only when there is permission to publish it.
- Add authentic screenshots, client names and testimonials only when verified and authorised.
- Review the site on mobile and desktop after deployment.

The current website does not submit or store visitor enquiries. No contact details, client relationships, performance metrics or completed deployments are invented.
